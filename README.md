Entry for the [Your AI Therapist's Diagnosis](https://make.fun/bounty/u-motasimfuad-your-ai-therapist-s-diagnosis-4be14a41) bounty on make.fun: the funniest single-line diagnosis an AI therapist hands its human, 200 characters or less.

`main.py` (Python 3.13, stdlib only) writes that one line to `<output dir>/entry.txt`, reading the output directory from `OUTPUT_DIR` when set, otherwise `/output`.

## Run

```sh
OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
